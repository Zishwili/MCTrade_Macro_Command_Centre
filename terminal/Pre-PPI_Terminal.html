9. Honest calibration status

What v2 is, and what it is not.

What v2 is

  • An exact reproduction engine for the v1 equation. Every one of the eight v1 calls is preserved bit-for-bit at default configuration.
  • A transparent audit tool: exact Z-scores, weighted contributions, flip-distances, and bootstrap fragility are all surfaced.
  • A look-ahead guard: computation is refused when any input is flagged unavailable at the forecast cutoff.
  • A NO SIGNAL classifier that refuses to output a directional call when |S| falls inside a user-configurable band. Only June 11 triggers it at default settings.
  • A manual-input model with full original section — eight numeric fields, gold-trend select, vintage cutoff text — all present and wired into the audit report.

What v2 cannot be

  • Out-of-sample skill. n = 8, p = 8 → df = 0. The weights are the unique exact solution of Z·w = y.
  • An independent prior. The reference means and SDs are the sample statistics of the same eight cases. True out-of-sample skill requires a prior-only reference window and ≥ ~30 releases.
  • A probability. S is a signed projection, not a win probability. The magnitude is not calibrated confidence.
  • A causal model. Signs of coefficients are fit artifacts under collinearity, not economic findings.

Roadmap to real validation

  1. Expand to ≥30 PPI releases across multiple regimes.
  2. Reduce to 3–5 predictors, pre-selected on economic grounds.
  3. Compute reference means/SDs point-in-time from data strictly prior to each forecast.
  4. Walk-forward test: one prediction at a time, weights re-fit only on prior data, labels pre-registered.
  5. Report calibration — hit rate with a confidence interval, Brier score, baseline comparison.
  6. Freeze the spec before seeing any outcome.
